- repository structure
- system boundaries
- dependencies
- data flow
- APIs

- reliability
- maintainability
- security implications

Do not modify code.

1. Current architecture
2. Problems
3. Proposed architecture
4. Trade-offs
5. Affected files
6. Risks
7. Implementation recommendations
